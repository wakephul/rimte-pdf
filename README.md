# RiMTe (Rimuovi Immagini e Testi)

Questo progetto è una semplice applicazione Streamlit sviluppata in Python per manipolare file PDF. Consente di cercare e rimuovere specifici blocchi di testo o immagini all'interno di un documento.

Il codice e la repository sono stati creati e vengono mantenuti esclusivamente per uso personale e privato. Non è garantito supporto, aggiornamento o idoneità per utilizzi in ambienti di produzione pubblici.
